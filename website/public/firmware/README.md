# Official badge firmware image

The `/sync` firmware section flashes these files in-browser over Web Serial
(`src/sync/FirmwareFlasher.jsx` with the vendored esptool-js bundle), so a
badge owner can reinstall the official image after a reset and then restore
their identity from the same page. The Advanced details on the page also link
the raw binaries with a manual esptool command as fallback.

| File | Flash offset | Source in `tools/rapid-flash/firmware` |
| --- | --- | --- |
| `bootloader.bin` | `0x0` | `bootloader/bootloader.bin` |
| `partition-table.bin` | `0x8000` | `partition_table/partition-table.bin` |
| `firmware.bin` | `0x10000` | `hello_world.bin` |
| `firmware.json` | - (manifest) | generated by `scripts/copy-firmware.mjs` |

`firmware.json` records each file's size and SHA-256 plus the image-set
`identity` digest (the same hash `rapid-flash` prints on startup), so the
version on the site can be compared with the mosaic operators check across
flash stations.

## Refreshing the committed image

Rebuild rapid-flash's badge set (`idf.py build` in the repo root, then copy
the outputs over `tools/rapid-flash/firmware/` per that tool's README), then
from the repo root:

```sh
node website/scripts/copy-firmware.mjs
node website/scripts/copy-firmware.mjs --check
git add website/public/firmware
```

The repo-root `.gitignore` ignores `*.bin`; the `.gitignore` in this folder
re-includes exactly the three names above plus the manifest, mirroring
`tools/web-flasher/firmware/`.
